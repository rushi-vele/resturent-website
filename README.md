# The Grand Table - Premium Restaurant Website

A luxury, modern static website for "The Grand Table" featuring glassmorphism, parallax effects, and smooth animations.

## 🚀 Deployment Instructions

To push this project to your GitHub repository (`https://github.com/rushi-vele/resturent-website.git`), please follow these steps:

1. **Install Git**: Download from [git-scm.com](https://git-scm.com/).
2. **Open Terminal**: In this project folder, run:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Luxury UI Update"
   git branch -M main
   git remote add origin https://github.com/rushi-vele/resturent-website.git
   git push -u origin main
   ```

## ✨ Features
- Fully responsive luxury UI.
- Interactive Table Booking system.
- Customer Review & Rating system.
- Smooth staggered scroll animations.
- Parallax hero section.
